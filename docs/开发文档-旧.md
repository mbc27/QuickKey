## 1. 项目可行性分析
### 1.1 项目优势
1. 细分赛道缺口明显：现有快捷键站点大多只覆盖PS、PR、VS Code等热门软件；BIM、岩土仿真、GIS、PLC、数控、化工色谱这类工业软件快捷键资料零散，搜索难度高，本项目差异化极强。
2. 用户需求刚性：设计师、工程师、科研人员高频查询快捷键提升效率；企业、工作室新人培训可直接作为手册。
3. 内容长期稳定，适合SEO：快捷键随版本改动频率低，长尾词数量巨大，竞争度低，可以持续获取稳定搜索流量。
4. 起步成本低：静态站方案，无数据库、无登录系统，运维压力可控。

### 1.2 风险与短板
1. 内容工作量巨大：清单内两千余款软件，大量冷门工业软件没有现成整理好的快捷键表，搜集、校对、区分版本、区分Windows/Mac是最大瓶颈。
2. 版权风险：快捷键操作方法本身不受版权保护；但禁止直接摘抄官方手册大段原文、随意使用未经授权素材；软件Logo仅做页面展示，不单独分发。
3. 本地收藏有局限：收藏数据保存在浏览器本地，清除缓存、换设备会丢失，页面明确提示该限制。
4. 持续维护压力：软件大版本更新会调整快捷键，冷门软件版本追踪成本高。

### 1.3 结论
✅ 项目值得做；本次直接落地V2能力，上线即具备更强体验；仍然坚持**热门优先、行业刚需其次、冷门随缘补充、用户投稿辅助**策略，不要一次性录完全部软件，分批持续补充内容。

## 4. 页面清单 & 页面需求说明
### 4.1 首页
1. 顶部导航：搜索框、全部分类入口、标签快速筛选、暗色模式切换按钮、收藏入口、关于、反馈投稿
2. 主体区域：热门软件推荐卡片、一级分类卡片（卡片展示该分类已收录软件数量）、最近更新软件列表
3. 底部：版权、ICP备案号、隐私政策、免责声明、关于页面链接
4. 交互：暗色模式全局生效，模式选择状态本地保存

### 4.2 分类列表页
1. 面包屑导航
2. 筛选控件：平台筛选（Windows/Mac/Linux）、标签筛选
3. 软件卡片：软件Logo、名称、简介、收录快捷键条数、版本标识
4. 排序选项：按更新时间 / 名称A-Z
5. 卡片悬浮：快速加入收藏按钮

### 4.3 软件详情页（核心页面）
1. 面包屑导航
2. 软件基础信息栏：Logo、名称、支持平台、可选版本下拉切换
3. Tab切换：Windows / Mac / Linux（无对应版本自动隐藏Tab）
4. 快捷键分组折叠面板：快捷键表格（按键｜功能），默认展开，支持收起全部/展开全部
5. 操作按钮组：单条复制、整页文本复制、导出Markdown、导出图片表格、加入收藏、加入对比队列
6. 侧边栏：同分类、同标签相关软件推荐
7. 底部：纠错入口、版本备注、更新时间、来源说明

### 4.4 快捷键对比页面
1. 支持从详情页添加2款软件进入对比队列
2. 左右分栏并排展示两套快捷键表，保持统一布局
3. 支持移除其中一个、清空对比队列
4. 支持切换两款软件各自的平台、版本
5. 适配移动端：移动端改为上下堆叠布局

### 4.5 搜索结果页
1. 展示搜索关键词
2. 优先匹配软件名称，其次匹配功能描述、标签
3. 每条结果卡片展示Logo、名称、版本、标签，点击跳转详情页
4. 无结果提示：暂未收录该软件，引导前往投稿页面提交收录建议

### 4.6 收藏页面
1. 展示用户本地收藏的全部软件卡片
2. 支持取消收藏、批量清空收藏
3. 页面顶部提示文案：收藏保存在浏览器本地，清理缓存/更换设备会丢失
4. 收藏数据存储：localStorage

### 4.7 反馈&投稿页面
分为两个表单模块：
- 纠错表单：软件名称、错误快捷键描述、正确内容、联系方式（选填）
- 投稿收录表单：软件名称、平台、版本、快捷键表格、来源说明、联系方式（选填）
> 使用第三方表单嵌入，不自研后端；表单提交后推送通知到微信/邮箱

### 4.8 关于页面
站点介绍、收录规则、素材说明、免责声明、更新计划、联系方式

## 6. UI & 交互规范
1. 整体风格：极简工具站，低冗余动画，优先可读性，工程工具风
2. 图标规范：
    - 全站组件图标统一使用 Tabler Icons 或 Heroicons（开源免费）
    - 软件Logo单独收集，统一规格：透明背景SVG/PNG，128×128，统一命名；仅用于页面展示，不打包分发
3. 配色：
    - 亮色模式：主色低饱和蓝色；正文深灰，次要文字浅灰；快捷键按键高亮，采用键帽样式
    - 暗色模式：深色背景，降低亮度，按键高亮区分，减少视觉疲劳
4. 表格：行高充足，间距宽松，区分表头；快捷键按键键帽样式增强识别
5. 交互细节：
    - 折叠面板平滑展开收起
    - 复制成功轻toast提示，自动消失
    - 暗色模式切换平滑过渡
    - 移动端对比布局自动切换上下堆叠
    - 收藏状态实时更新，页面刷新不丢失

## 8. 开发前前置准备清单
> 本部分为正式启动设计、开发之前必须完成的准备工作，可并行推进。

### 8.1 品牌、名称、文案准备（最先完成，1天内）
1. 确定站点正式名称、域名，核验域名是否可用、无商标冲突；确定slogan
2. 定稿全站固定复用文案：首页简介、免责声明、隐私政策、关于页面文案、反馈页面说明、收藏页提示文案、底部版权文案
    > 免责核心句：快捷键仅供参考，以软件官方为准，不保证版本完全一致；收藏数据保存在本地浏览器，清理缓存会丢失
3. 锁定需求边界：本次交付内容固定，开发阶段不再随意新增需求；明确不收录网页软件、破解/外挂类软件

### 8.2 数据与结构准备（地基，确定后不修改字段）
1. 定稿快捷键数据字段表（本文档3.3章节）
2. 锁定完整分类目录树，与文档信息架构保持一致
3. 准备录入模板：Excel / Markdown表格模板，附带示范样例（VS Code或AutoCAD），标注必填项
4. 定稿URL规则，交付开发

### 8.3 素材准备
1. 图标方案确认：方案A，组件图标使用Tabler Icons / Heroicons；软件Logo单独收集，统一规格透明128×128 PNG/SVG
2. 收集UI参考站点2~3个，明确布局偏好
3. 确定组件样式参考：搜索框、键帽表格样式、折叠面板、toast提示、暗色模式配色

### 8.4 第三方服务准备
1. 选择第三方表单平台（腾讯表单/金数据/飞书表单等），提前建好纠错表单、投稿表单，配置微信/邮箱通知，拿到嵌入链接
2. 选择统计工具：Umami / 百度统计，提前注册拿到统计ID，开发时埋入页面

### 8.5 托管、域名、备案方案确认（周期最长，优先启动）
二选一：
- 方案A（主推，面向国内用户，SEO友好）：国内域名+国内轻量服务器 + ICP备案；备案周期10–20天，可以和开发并行提交
- 方案B（仅测试）：Cloudflare Pages / Vercel免费静态托管；国内访问不稳定，不适合正式流量运营
额外确认：是否需要CDN加速

### 8.6 内容储备（和开发并行执行）
1. 建立素材目录，按Tier分级管理内容
    - Tier1（优先）：PS、PR、VS Code、CAD、Revit、Office等高流量软件
    - Tier2（差异化行业）：广联达、YJK、Midas、QGIS、Altium等行业刚需软件
    - Tier3：冷门软件，随缘补充，优先处理用户投稿
2. 录入规范：Windows、Mac、Linux分开；标注软件版本；不确定快捷键标记【待验证】
3. 上线最低内容目标：至少50款校验完成软件，不空站上线

### 8.7 测试文档准备
提前编写【上线验收检查表】，开发交付后逐项核对。

## 9. 内容运营方案
1. 录入节奏：上线初期每周新增10–20款软件；建立待收录清单，依靠投稿表单收集用户提交内容，人工审核后上架
2. 校验规则：优先参考官方帮助文档；社区来源内容标注来源；信息冲突时以软件内置设置为准
3. 引流渠道：行业论坛、知乎、小红书、B站简介，面向工程、设计圈子引流

## 10. 部署、服务器与成本规划
静态站方案，无数据库：
- 数据存储形式：JSON结构化数据，前端渲染页面
- 优点：稳定、低带宽、几乎零宕机；缺点：新增软件、新增版本需要更新数据文件，重新构建部署
- 长期迭代：当内容体量巨大后，可迁移至Hugo/VitePress等静态CMS

## 11. 盈利路径规划（前期优先沉淀内容，晚变现）
1. 广告：百度联盟，仅放置侧边栏、页面底部，快捷键表格区域禁止广告
2. 友链置换：BIM、CAD、设计素材、教程站点互换链接
3. 增值：全套快捷键Markdown/Excel打包下载（远期考虑，不在本次开发范围）
4. 行业合作：培训机构、软件代理商推荐合作

## 12. 风险预案
1. 内容错误：固定免责声明+一键纠错通道，收到反馈及时修正
2. 收录速度慢：开放投稿，用户提交后人工审核上架
3. 版权风险：不复制官方大段原文；软件Logo仅页面展示、不二次分发；拒绝破解相关内容
4. 收藏丢失风险：页面持续提示本地存储限制，不向用户承诺跨设备同步
5. 流量不及预期：依靠海量长尾词长期积累，不依赖大流量词
